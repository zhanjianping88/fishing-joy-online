About Ocean Arcade Game

Ocean Arcade Game is a small hobby site built around one fish game I kept wanting to tidy up, plus a few side pages and route ideas that made the whole thing feel more alive.

What this site is for

Ocean Arcade Game is an independent hobby project for people who want a short browser arcade session without an install or account. The main game is a fish-targeting game: aim with a mouse or touch screen, choose a cannon power, and time shots as fish cross the playfield.

The site includes a focused game page, a slower Deep Sea route, a faster Ocean Hunter route, and beginner guides. “Ocean Hunter” is the name of this site's faster route; it describes the play mode here. The site is not an official Sega page and does not claim to host Sega's original Ocean Hunter arcade game.

Start with the browser fishing game, read how to play, or see the Ocean Hunter route.

Open source foundation

The featured fishing game is adapted from imtonyjaa/ggemu-fishing-joy and uses PixiJS for its browser rendering. The site also includes a separate riichi mahjong app adapted from kobalab/Majiang.
